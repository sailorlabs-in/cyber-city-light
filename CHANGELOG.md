# Change Log

All notable changes to the "cyber-city-light" extension suite will be documented in this file.

## [1.1.0] - 2026-11-02

### Added
- **Rainbow Bracket Pair Colorization**: Distinct cyberpunk neon colors for bracket levels 1-6 across all four theme flavors.
- **Bracket Pair Guides**: Neon-tinted bracket guide lines (active and inactive) for enhanced code structure visualization.
- **Editor Sticky Scroll**: Full styling support for sticky scroll headers in classes, functions, and markdown.
- **Semantic Highlighting (`semanticTokenColors`)**: Added rich semantic coloring for interfaces, types, readonly variables, parameters, and namespaces.
- **Modern Command Center & Quick Input**: Themed top navigation search bar and quick open palette.
- **Notification Toast & Center**: Cyberpunk styling for toasts, progress indicators, and status badges.
- **Inlay Hints**: Distinct subtle hints for parameter names and inferred types in TypeScript, Rust, Go, and Python.
- **Testing Explorer UI**: Cyberpunk status icons for passed, failed, and running tests.

### Optimized
- **Web IDE Performance**: Streamlined extension package down to ~175 KB (over 90% size reduction) for instant loading in `vscode.dev` and `github.dev`.
- **Packaging (`.vscodeignore`)**: Excluded design banners and local build artifacts from distribution bundle.
- **Retina Icon**: Optimized 256×256 icon asset.

## [1.0.0] - Initial Release

- Initial release of Cyber City Light Theme Suite:
  - ☀️ **Cyber City Light** (Light mode)
  - 🌌 **Cyber City Dark** (Dark mode)
  - 🌇 **Cyber City Dusk** (Sunset warm dark mode)
  - 🌃 **Cyber City Midnight** (High-contrast midnight dark mode)
- Full static support for VS Code Desktop and VS Code for the Web (`vscode.dev`, `github.dev`).
